# Drill Core — Gameplay Research

**[Read the report](https://condrusarsen.github.io/deep-contract/research.html)** or download the report ZIP from the [release](https://github.com/CondrusArsen/deep-contract/releases/tag/v1.0.0). The English HTML report contains 47 embedded images and can be opened offline.

Start with **One platform, two directions**, the day/night loop, the coal gate, launch/progression and **Build layer & web adaptation**. Compare the analysis with [Deep Contract's design notes](../DESIGN.md).

The report records research from September 2026. Market figures are dated observations. Verified observations, inferences, unverified report claims and unknowns are distinguished inside the document. Original-game screenshots and external gameplay evidence retain their attribution.

This is an independent study of Drill Core. Deep Contract is the separate browser game presented in this repository; its graphics, sound and font credits are documented in [ASSETS.md](../ASSETS.md).
