# Drill Core — Design Research

Download and open [Drill-Core-teardown.html](Drill-Core-teardown.html) in a browser. It is a self-contained English report with 47 embedded images. GitHub displays HTML as source; use **Raw → Save as** or download the repository to read the formatted report.

For a focused first read, start with **One platform, two directions**, the day/night loop, the coal gate, launch/progression and **Build layer & web adaptation**. Then compare those decisions with [Deep Contract's design notes](../DESIGN.md).

The report preserves a historical research snapshot from September 2026, including the versions and evidence boundaries described inside it. Market figures are dated observations, not current statistics. Some findings come from attributed external gameplay evidence and AI-assisted analysis. The report is an unofficial analysis of Drill Core, not work on the original commercial title.

The browser implementation in this repository is a separate project. Its visual/audio assets and renamed content are documented in [ASSETS.md](../ASSETS.md).
