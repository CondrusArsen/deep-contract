# Download Packages

[Latest standalone release](https://github.com/CondrusArsen/deep-contract/releases/tag/v1.0.0)

| File | Contents |
|---|---|
| DeepContract-playable.zip | Standalone game, opening instructions and asset credits |
| Drill-Core-teardown.zip | Illustrated research report and reading guide |
| DeepContract-standard.zip | Game with the original cover and screenshots |
| DeepContract-thumbnail.zip | Game with the alternate thumbnail presentation |
| DeepContract-mobile.zip | Game with the mobile-cover presentation |

All three presentation packages contain the same current game build. Their artwork and metadata differ; they are not different gameplay implementations. GitHub also provides a source-code ZIP for this release.

The current edition uses local saves and runs independently in a browser. [Play online](https://condrusarsen.github.io/deep-contract/).

Earlier repository revisions and release packages are historical snapshots. The current source, game and documentation are available in the latest release.
